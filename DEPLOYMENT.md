# 🚀 Инструкция по развертыванию сайта Юридикон

## Вариант 1: Развертывание на Vercel (РЕКОМЕНДУЕТСЯ - 5 минут)

### Шаг 1: Создайте GitHub репозиторий
1. Откройте https://github.com/new
2. Назовите репозиторий: `juridicon-consulting`
3. Нажмите "Create repository"

### Шаг 2: Залейте код на GitHub
```bash
cd C:\Users\User\juridicon-consulting
git remote add origin https://github.com/YOUR_USERNAME/juridicon-consulting.git
git branch -M main
git push -u origin main
```

### Шаг 3: Развертите на Vercel
1. Откройте https://vercel.com
2. Нажмите "Sign Up" (или "Sign In" если у вас есть аккаунт)
3. Выберите "Continue with GitHub"
4. После авторизации нажмите "Import Project"
5. Введите URL вашего репозитория
6. Нажмите "Import"
7. Нажмите "Deploy"

**Готово!** Сайт будет доступен по адресу:
- `https://juridicon-consulting.vercel.app` (автоматический)
- Или укажите свой домен в настройках Vercel

## Вариант 2: Развертывание на Netlify (5 минут)

1. Откройте https://app.netlify.com/signup
2. Выберите "GitHub"
3. После авторизации нажмите "New site from Git"
4. Выберите репозиторий `juridicon-consulting`
5. Нажмите "Deploy site"

## Вариант 3: Локальное развертывание

### Запуск в режиме разработки:
```bash
cd C:\Users\User\juridicon-consulting
npm run dev
```
Сайт будет доступен на http://localhost:3000

### Сборка для production:
```bash
npm run build
npm run start
```

## 🎨 Настройка сайта

### Изменение логотипа
В `app/page.tsx` найдите раздел с логотипом (буква "Ю") и измените:
- Цвет
- Размер
- Стиль

### Добавление фотографий
Все фотографии берутся из Unsplash (бесплатный сервис). Чтобы заменить:
1. Откройте https://unsplash.com
2. Найдите нужное фото
3. Скопируйте URL полного разрешения
4. Замените URL в коде (файл `app/page.tsx`)
